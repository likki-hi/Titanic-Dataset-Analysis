# 🚢 Titanic Dataset Analysis

## 📌 data analystics with Python Internship – Task 2

This project analyzes the famous Titanic dataset using Python to understand the survival patterns of passengers based on gender, passenger class, and age group.

## 🎯 Objective

The main objectives of this project are:

- Load and explore the Titanic dataset
- Handle missing values
- Analyze survival patterns
- Calculate survival rates
- Create data visualizations
- Draw meaningful conclusions from the data

## 🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
- Kaggle Titanic Dataset

## 📂 Dataset

The Titanic dataset contains information about passengers, including:

- Passenger ID
- Survival status
- Passenger class
- Name
- Gender
- Age
- Fare
- Number of siblings/spouses
- Number of parents/children
- Cabin
- Embarked port

The analysis uses the `train.csv` dataset.

## 🧹 Data Cleaning

The dataset was checked for missing values.

The missing values in the `Age` column were handled by replacing them with the mean age.

Average age used:

**29.70 years**

## 📊 Analysis Performed

### 1. Survival by Gender

- Female survival rate: **74.20%**
- Male survival rate: **18.89%**

### 2. Survival by Passenger Class

- 1st Class: **62.96%**
- 2nd Class: **47.28%**
- 3rd Class: **24.24%**

### 3. Survival Rate by Age Group

- Child: **57.97%**
- Teenager: **42.86%**
- Young Adult: **35.33%**
- Adult: **40.00%**
- Senior: **22.73%**

## 📈 Visualizations

The project includes:

- Survival by Gender bar chart
- Survival by Passenger Class bar chart
- Survival Rate by Age Group bar chart
- Passenger Age Distribution histogram

## 🔍 Key Findings

The analysis shows that survival rates differed across gender, passenger class, and age groups in the Titanic training dataset.

Female passengers had a higher observed survival rate than male passengers. Survival rates also varied by passenger class, with different rates for first, second, and third class. Age groups also showed differences in observed survival rates.
